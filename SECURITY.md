# Security policy

## Scope

This repository holds a dependency-free MCP server (`src/server.mjs`), an
OpenAPI description, and a reference Next.js implementation of the read-only
API. It handles no credentials and stores no user data.

## Reporting a vulnerability

Please report privately through GitHub's
[private vulnerability reporting](https://github.com/jp-pietrini/remittances-api-mcp/security/advisories/new)
rather than a public issue. Expect an acknowledgement within a week.

Data accuracy problems (wrong figures, missing periods) are not security
issues; open a regular issue and name the source series.
